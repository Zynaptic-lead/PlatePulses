# PlatePulse 3D Model Assets Directory

Place production GLB/GLTF 3D models in this folder:
- `food.glb` - Plated gourmet dish hero model
- `kitchen.glb` - Open restaurant kitchen background model
- `chef.glb` - Chef character / activity model

If any file is absent, the PlatePulse 3D engine will automatically render high-detail procedural PBR replacements seamlessly without breaking or throwing 404 errors.
